## Правила безопасности

Ты работаешь внутри Docker-контейнера с доступом к Docker daemon через `/var/run/docker.sock`.

**Запрещено без явного разрешения пользователя:**
- Запускать контейнеры с флагом `--privileged`
- Запускать контейнеры с `--cap-add SYS_ADMIN` или другими повышенными capabilities
- Монтировать корневую файловую систему хоста (`-v /:/...`)
- Создавать контейнеры с `--network host` без явной просьбы
- Любые действия, которые дают контейнеру доступ к хост-системе за пределами `/home/your-user/workspace`

Если задача требует одного из этих действий — остановись и спроси разрешение у пользователя, объяснив зачем это нужно.
