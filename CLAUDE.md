# CLAUDE.md

Контекст для Claude Code при работе с этим репозиторием.

## Что это

Build-контекст Docker-образа `claude-course:latest` — рабочей среды курса «Claude Code: суперсила
для НЕпрограммистов» (Automatica). Корень репозитория одновременно и контекст сборки образа, и
оркестрация одиночного контейнера для локального запуска (`docker-compose.yml`, `run.sh`).

Тот же образ разворачивается на VPS по контейнеру на студента — те скрипты живут в основном
репозитории курса и сюда не входят.

## Две половины

1. **Образ** — `Dockerfile`, `entrypoint.sh`, `auth-gateway.py`, `login.html`,
   `claude-settings.json`, `code-server-settings.json`.
2. **Материалы** — `course/` (5 сессий, 33 демо, слайды занятий в `sessions/0X-*/slides/`) и
   `skills/` (20 навыков). Это то, что видит студент внутри контейнера.

`course/` и `skills/` — курируемые копии из основного репозитория курса, а не зеркала. Правки в
демо и навыках делаются там и переносятся сюда целиком.

## Что важно помнить

- **Версия Claude Code закреплена** в `Dockerfile` (`ARG CLAUDE_CODE_VERSION`). Не снимайте пин:
  без него пересборка молча переводит весь поток на новый релиз. Поднимайте осознанно и проверяйте
  на одном контейнере.
- **code-server раздаётся в корне `/`**, а не под подпутём. Под подпутём он отдаёт относительные
  эндпоинты, service worker для webview не регистрируется и ломается превью Markdown.
  `auth-gateway.py` резервирует `/login`, `/logout`, `/healthz` и `/files/`, остальное проксирует в
  code-server.
- **Секретов в репозитории нет.** Ключ приходит через `.env` (`GLM_API_KEY`) и подмешивается в
  `~/.claude/settings.json` при старте — Claude Code читает окружение именно оттуда, одного
  `~/.claude/.env` мало.
- **Работа студента живёт в volume** `student-data` (`/home/coder/course`). Первый запуск копирует
  материалы из `~/.course-image`. `docker compose down -v` стирает volume вместе с работой — на
  живом потоке так делать нельзя.
- **Agent Teams** (сессия 5) включены через `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1` на уровне
  образа. Без переменной команда агентов не создаётся.
- После правки `Dockerfile`, `course/` или `skills/` образ надо пересобрать.

## Язык

Материалы курса и документация — на русском. Комментарии в коде — по языку окружающего файла.
