# Продвинутое демо: операционный разбор из трёх источников

## Задача

Вместо одного CSV Claude должен связать заказы, обращения поддержки и плановые показатели. В данных есть отменённые заказы, просрочки, нарушение SLA и клиент с высокой выручкой, у которого одновременно растёт число обращений.

Файлы:

- `orders.csv` — 12 заказов с выручкой, себестоимостью и сроками;
- `support-tickets.csv` — 12 обращений с приоритетом и временем реакции;
- `targets.md` — определения метрик и целевые значения.

## Основной промпт

```text
Прочитай все файлы в папке. Сначала проверь качество данных и опиши правила расчёта. Затем подготовь operations-review.md и operations-dashboard.html.

Нужно:
1. Выручка и валовая маржа только по completed-заказам.
2. Доля заказов, завершённых в срок. Отменённые не включать в знаменатель.
3. SLA поддержки по каждому приоритету и список нарушений.
4. Сводка по customer_id: выручка, маржа, заказы с задержкой, число тикетов.
5. Три риска с доказательствами и три конкретных действия.
6. Контрольные суммы и отдельный список допущений.

Исходные файлы не меняй. Если метрика неоднозначна, сначала задай вопрос или явно зафиксируй допущение.
```

## Почему пример сложнее

Claude должен объединить источники по `customer_id`, применить разные правила фильтрации и не перепутать выручку с денежным потоком. Хороший результат объясняет формулы и позволяет вручную проверить каждую тревожную цифру.

## Проверка результата

- отменённый заказ `O-108` не входит в выручку и on-time rate;
- заказ `O-104` имеет отрицательную маржу;
- тикеты `T-203`, `T-207`, `T-209` и `T-212` нарушают SLA первой реакции;
- клиент `C-03` одновременно даёт крупную выручку и имеет два критичных обращения;
- в отчёте есть номера исходных строк или ID, а не только выводы.

## Усложнение

```text
Добавь stress-test: что произойдёт с общей валовой маржой, если себестоимость всех незавершённых заказов вырастет на 12 %, а два просроченных заказа дадут штраф 5 % от выручки. Покажи формулу и не смешивай сценарий с фактом.
```
