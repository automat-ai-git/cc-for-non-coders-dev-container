# Правила штаба реагирования

- Исходники `incident-log.md` и `affected-customers.csv` не редактировать.
- Факт, гипотеза и неизвестное всегда маркируются отдельно.
- Не обещать ETA и отсутствие потери данных без подтверждения incident commander.
- Публичные сообщения не содержат имён клиентов, внутренней архитектуры и неподтверждённой причины.
- Каждый teammate пишет только назначенный ему файл.
- При изменении фактов добавлять changelog с временем, а не стирать предыдущую версию.
- Время следующего обновления указывать даже при отсутствии нового ETA.
