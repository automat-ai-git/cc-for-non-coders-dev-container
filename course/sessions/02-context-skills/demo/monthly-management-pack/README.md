# Продвинутое демо: ежемесячный пакет для руководителя

## Что показываем

Проектный `CLAUDE.md` задаёт управленческий контекст, а Skill `management-pack` описывает повторяемую процедуру. Claude сводит продажи, денежный поток, статус проектов и KPI, проверяет расхождения и готовит один отчёт для планёрки.

## Запуск

```text
/management-pack июнь 2026
```

Если Claude Code был запущен до появления первой папки `.claude/skills/`, перезапустите сессию.

## Ожидаемый результат

Файл `management-pack-2026-06.md` со следующими разделами:

1. executive summary на 7–10 строк;
2. продажи: оплачено, выставлено, прогноз;
3. cash flow: входящие, исходящие, чистый поток;
4. проекты: статус, просрочки, зависимые решения;
5. KPI план/факт;
6. расхождения между источниками и вопросы владельцам данных;
7. три решения для планёрки.

## Контрольные точки

- «Оплачено» в `sales.csv` не равно всем входящим в `cashflow.csv`: в cash flow есть предоплата за июль.
- Проект Atlas отмечен как `yellow`, хотя бюджет не превышен: причина — просрочка интеграции.
- KPI по марже нельзя считать по cash flow; используется выручка и прямые затраты из продаж.
- Любое расхождение нужно показать, а не «исправить» молча.

## Усложнение

```text
/management-pack июнь 2026 -- добавь сценарий: перенос оплаты S-008 на июль и рост прямых затрат по Atlas на 15 %. Факт оставь без изменений.
```
