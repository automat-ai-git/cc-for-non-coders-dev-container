# Контекст проекта

Мы готовим продуктовые тексты для B2B CDP-платформы DataPulse.

## Правила

- Пиши на русском языке, деловым и ясным тоном.
- Не меняй факты, числа, названия технологий и ограничения из `product-description.md`.
- Не выдумывай ROI, клиентов, сертификаты или функции продукта.
- Для каждой аудитории меняй отбор фактов и объяснения, а не только лексику.
- Сохраняй версии в отдельные файлы; исходник не редактируй.
