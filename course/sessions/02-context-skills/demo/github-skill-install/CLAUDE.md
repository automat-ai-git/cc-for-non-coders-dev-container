# Безопасная установка Skills

- Проектные Skills устанавливай только в `.claude/skills/<skill-name>/SKILL.md`.
- Перед установкой покажи источник, структуру файлов и кратко объясни, что Skill делает.
- Не запускай скрипты из чужого репозитория без отдельного подтверждения.
- Не устанавливай Skill, который запрашивает секреты или слишком широкие права, пока пользователь не проверит его инструкции.
- После установки проверь навык явным вызовом `/<skill-name>` на тестовых данных.
