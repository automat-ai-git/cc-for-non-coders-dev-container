# Еженедельный отчёт

## Источники

1. `sales.csv` — продажи за текущую и прошлую недели.
2. `expenses.csv` — расходы текущей недели.
3. `tasks.md` — задачи и статусы.
4. `kpi.md` — план и факт по KPI.

## Порядок работы

1. Проверь наличие всех четырёх файлов и структуру таблиц. Если файл или обязательная колонка отсутствует, остановись и перечисли проблему.
2. Посчитай продажи текущей и прошлой недели только для статуса `оплачено`. Отдельно покажи суммы по статусам `счет выставлен`, `переговоры` и `отказ`.
3. Сверь итоговые суммы повторным расчётом по исходным строкам.
4. Сгруппируй расходы по категориям и покажи общую сумму.
5. Посчитай выполненные, текущие и просроченные задачи. Для просроченных укажи ответственного и срок.
6. Для KPI рассчитай процент выполнения и отдельно отметь значения ниже 80 %.
7. Заверши отчёт пятью приоритетами: что хорошо, что требует внимания и какие решения нужны. Не приукрашивай.

## Формат

Сохрани Markdown-файл `weekly-report-YYYY-MM-DD.md`, где дата — понедельник отчётной недели. Используй таблицы, суммы вида `1 234 567 руб.` и отдельный блок `Контрольные суммы`.
