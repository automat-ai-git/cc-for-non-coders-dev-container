# Правила сравнения договоров

- Сравнивай только тексты из этой папки; не додумывай отсутствующие условия.
- Для каждого изменения цитируй номер пункта старого и нового договора.
- Отделяй точный расчёт от правовой оценки.
- Объясняй риски простым языком и отмечай, что финальное заключение даёт юрист.
- Все промежуточные вычисления показывай явно: ставка × площадь × период.
