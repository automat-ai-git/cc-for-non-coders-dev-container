# Правила скрининга резюме

- Оценивай кандидатов только по критериям из `job-requirements.md`.
- Не используй пол, возраст, семейное положение и другие защищённые признаки.
- Не додумывай опыт, навыки или мотивацию по имени и должности.
- Для каждого балла приводи конкретное подтверждение из CSV и отмечай пробелы в данных.
- Результат — помощь рекрутеру, а не автоматическое решение об отказе.
- Сохраняй исходный CSV без изменений.
