# Политика мониторинга поставщиков

- Используй веб-MCP только для публичных данных; не отправляй ему внутренние комментарии из CSV целиком.
- Предпочитай официальные status, trust, security, legal и privacy-страницы поставщика.
- Не делай вывод «инцидентов не было» только потому, что поиск ничего не вернул.
- Любое событие должно иметь URL и дату проверки.
- Не интерпретируй юридические документы как юрист; формулируй вопросы для ИБ и legal.
- Исходный реестр не редактировать.
