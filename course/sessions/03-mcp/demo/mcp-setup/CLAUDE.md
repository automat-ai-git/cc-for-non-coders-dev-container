# Правила настройки MCP

- Используй `claude mcp add`, `claude mcp list` и `/mcp`; не записывай MCP в `.claude/settings.json`.
- Для общего проектного конфига используй `.mcp.json` и `--scope project`.
- Никогда не вставляй реальные API-ключи в файлы-примеры или ответы.
- Перед подключением объясни, локальный сервер или удалённый, какие данные он получает и какие права нужны.
- После добавления проверь статус и один безопасный тестовый запрос.
