# Правила board pack

- Аудитория: совет директоров, время чтения основного документа — до 10 минут.
- Факт, прогноз и pipeline показывать отдельно.
- Не выбирать одну из противоречивых цифр без объяснения.
- Для каждого риска нужны владелец, срок и ранний индикатор.
- Субагенты работают только на чтение и возвращают структурированные выводы.
- Единственный автор `board-pack.md` — основной агент.
