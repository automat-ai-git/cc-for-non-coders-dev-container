# Операционный статус

## Метрики

| Метрика | Цель | Факт |
|---|---:|---:|
| Проекты в срок | 90 % | 71 % |
| SLA поддержки | 95 % | 92 % |
| Повторные открытия тикетов | до 6 % | 9 % |
| Миграция клиентов на платформу v2 | 100 % | 90 % |

## Блокеры

- Три enterprise-проекта задержаны из-за интеграции с 1С.
- На второй линии поддержки вакантны две позиции; backlog вырос с 84 до 137 тикетов.
- Миграция v2: команда считает завершёнными клиентов, которые перенесли данные, даже если обучение пользователей ещё не закончено.

## Решения

- Нужен бюджет 480 000 руб. на временную команду интеграции на шесть недель.
- Нужна единая трактовка «миграция завершена» до публикации KPI клиентам.
