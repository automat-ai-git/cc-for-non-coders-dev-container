# Продвинутое демо: пакет к совету директоров через субагентов

## Сценарий

Через час совет директоров. Нужно параллельно проверить финансы, операционные показатели и реестр рисков, а затем собрать непротиворечивый пакет. В проекте уже определены три read-only субагента в `.claude/agents/`.

## Роли

- `finance-analyst` — считает выручку, расходы, прибыль, маржу и отклонения.
- `operations-analyst` — проверяет SLA, просрочки и зависимости.
- `board-skeptic` — ищет противоречия, слабые доказательства и неудобные вопросы.

## Основной промпт

```text
Подготовь пакет к совету директоров по файлам в этой папке.

Запусти параллельно finance-analyst и operations-analyst. После их результатов передай выводы board-skeptic для критической проверки. Затем сам собери board-pack.md.

Требования:
- 1 страница executive summary;
- таблица план/факт и формулы ключевых метрик;
- 5 рисков с владельцем, сроком и ранним индикатором;
- противоречия между файлами не исправлять молча;
- отдельный раздел «Решения, требуемые сегодня»;
- приложение с вопросами board-questions.md и краткими ответами из данных.

Субагенты ничего не редактируют. Итоговый файл пишет только основной агент.
```

## На что смотреть

1. Первые два субагента действительно идут параллельно.
2. В основной контекст возвращаются выводы, а не вся промежуточная работа.
3. Скептик замечает, что `operations.md` называет миграцию завершённой на 90 %, а реестр рисков — на 72 %.
4. Основной агент не выбирает удобную цифру, а выносит расхождение в вопросы.
5. Финансовый агент не считает неоплаченный pipeline выручкой.

## Усложнение

```text
Попроси board-skeptic отклонить пакет, если хотя бы одна ключевая цифра не имеет формулы или источника. После замечаний исправь пакет и добавь changelog.
```
