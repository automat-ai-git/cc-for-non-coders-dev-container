# Учебный проект: Skills, команды и hooks

- Файлы в `.claude/commands/` — учебные slash-команды; не меняй их без явной просьбы.
- Hooks получают JSON через stdin. Не используй вымышленные переменные `CC_TOOL_*`.
- Блокирующий `PreToolUse` hook должен завершаться кодом 2 и писать причину в stderr.
- Не ослабляй защитный hook ради демонстрации.
- Сгенерированные отчёты сохраняй только в `reports/` или `briefs/`.
