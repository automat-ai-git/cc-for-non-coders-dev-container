# Правила протокола

- Единственный источник фактов — `meeting-transcript.md`.
- Отличай принятое решение от предложения, вопроса и шутки.
- Для каждой задачи указывай ответственного, срок и таймкод; отсутствующее поле помечай `не назначено`.
- Не исправляй противоречия молча: вынеси их в «Требует уточнения».
- Формальный протокол и сообщение для Telegram должны содержать одинаковый набор решений и задач.
