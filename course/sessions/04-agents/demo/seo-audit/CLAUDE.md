# Правила SEO-аудита

- Аудитируй только данные из `blog-articles.csv`, если пользователь отдельно не попросил веб-проверку.
- Для каждого приоритета указывай сработавшие критерии: возраст, объём, meta description, тема, каннибализация.
- Не утверждай, что статья «не ранжируется», без данных о позициях и трафике.
- Не предлагай удаление без варианта redirect/merge и проверки органического трафика.
- Исходный CSV не меняй; результаты сохраняй в отдельные файлы.
